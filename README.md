# Chart Studio

A focused chart-making application for analysts who already have their final analytical tables or series.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Workflow

Upload CSV/Excel → choose chart → map columns → customize → export PNG/SVG.

## Current chart types

- Bar
- Horizontal bar
- Line
- Area
- Scatter
- Pie
- Donut
- Histogram
- Box plot

## Current customization

- Style presets
- Title/subtitle
- Data labels
- Gridlines
- Legend
- Dimensions
- Sorting
- Top N
- Reference line
- PNG/SVG export
